# C# Console Apps

Aplicações de console em **C# / .NET 9** desenvolvidas durante o curso *Fundamentos do C#* do balta.io, praticando lógica, entrada e saída no console e manipulação de arquivos.

| Projeto | O que faz |
|---|---|
| [Calculator](./Calculator) | Calculadora por menu com as quatro operações, potência e raiz quadrada |
| [Stopwatch](./Stopwatch) | Cronômetro que conta segundos (`10s`) ou minutos (`1m`) informados pelo usuário |
| [TextEditor](./TextEditor) | Editor de texto simples: cria e salva arquivos e abre arquivos existentes |

## Como executar

Pré-requisito: [.NET 9 SDK](https://dotnet.microsoft.com/download).

```bash
cd Calculator   # ou Stopwatch / TextEditor
dotnet run
```
